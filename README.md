# Revenge - Cosmic Full-Stack Website

A fast, responsive, full-stack demo website built from scratch in 7 hours.  
Modern dark-cyan cosmic theme with product grid, review system, and clean UI.

Live demo: https://revenge.fwh.is

## Features

- Responsive design (mobile-first)  
- Cosmic dark theme with gradients & animations  
- Product showcase grid  
- Review system (form + SQLite backend)  
- Contact-ready layout  
- Built with pure HTML/CSS/JS + PHP + SQLite (no frameworks)

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript  
- Backend: PHP  
- Database: SQLite (local file-based)  
- Hosting: InfinityFree (free PHP + file hosting)

## How to Run Locally

1. Clone or download the repo  
2. Place all files in your server root (htdocs or similar)  
3. Ensure PHP is enabled (Apache/XAMPP/WAMP/etc.)  
4. Open `index.html` or `index.php` in browser  
5. Submit reviews → they save to `reviews.db` (creates automatically)
